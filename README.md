# Circles

Draw any closed loop using ![Fourier epicycles](https://www.dynamicmath.xyz/fourier-epicycles/)

## Build

### Dependencies

- Nix develop (if you use nix)

![Raylib](https://github.com/raysan5/raylib)  
![Ninja](https://github.com/ninja-build/ninja) (Optional)

```bash
git clone https://github.com/piyush-1337/circles.git
cd circles

mkdir build
cd build

cmake .. -G Ninja   # or cmake ..
ninja               # or make
```

### Run:
./circles
